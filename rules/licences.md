# licences that state reuse is permitted; they gate nothing

A post's page states the author's licence, and whether it is one of these, which permit reuse. The list gates nothing: quoting and forking need no permission, and every attributed post can be forked whatever its licence.

```diff-me-rule
{"permit_reuse":["CC-BY-4.0","CC-BY-SA-4.0","CC0-1.0","MIT","Apache-2.0","BSD-2-Clause","BSD-3-Clause","ISC","Unlicense"]}
```
